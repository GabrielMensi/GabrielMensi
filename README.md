### 🚀 About Me

I'm a frontend developer who's spent the last 4 years as the lead frontend engineer on close to
20 production projects for clients across automotive, fintech, industrial, and wealth management.
I specialize in **Next.js**, **React**, and decoupled **Django/Wagtail CMS** architectures — I
co-led my agency's migration from monolithic Django templates to this stack, and it's now the
standard for every new project we ship.

💡 I like building the boring-sounding infrastructure that makes everything else fast to build on
top of: normalization layers, reusable component systems, and CMS integrations that let
non-technical teams manage full pages without touching code.

### 🌍 Open Source Contributions

- 🇦🇷 [ai-job-search](https://github.com/GabrielMensi/ai-job-search) — Argentina/LatAm fork (maintainer)  
  Adapted an AI-powered job-search framework (originally built for the Danish market) for
  Argentina/LatAm: 10 new job-portal integrations (GetOnBoard, Computrabajo, Bumeran, Zonajobs,
  Empleos IT, and others), each a zero-dependency CLI with its own test suite.  
  Also proposed and got **merged upstream** two market-agnostic features:
  - A **dynamic, per-user language-eligibility gate** — replacing a hardcoded language
    assumption with a general rule driven by the candidate's own declared languages and
    proficiency levels.
  - A **company-research cache** shared between the CV/cover-letter drafting workflow and
    the interview-prep workflow — removes duplicate research passes on the same company.  
  → Original project: [MadsLorentzen/ai-job-search](https://github.com/MadsLorentzen/ai-job-search)

- 🧠 [Resume Matcher](https://github.com/srbhr/Resume-Matcher)  
  Contributing to an AI-powered tool that helps match resumes with job descriptions.  
  My contributions include schema improvements, bug fixes, issue triaging and active feature discussions.  
  → Learn more at: [resumematcher.fyi](https://resumematcher.fyi/about)
